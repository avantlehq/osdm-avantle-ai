## Lessons Learned

### What Worked Well
1. Complete reset approach (clean slate vs incremental fixes)
2. Comprehensive documentation before coding
3. Monorepo structure planning upfront
4. Version control discipline (proper v1.0.0, removed invalid tags)

### Challenges Overcome
1. **Vercel Framework Detection**
   - Issue: Vercel insisted on Next.js framework
   - Solution: Added minimal Next.js shim temporarily

2. **Package Manager Conflicts**
   - Issue: pnpm detected from parent directory
   - Solution: `.npmrc` + explicit `installCommand`

3. **Missing TypeScript Types**
   - Issue: Next.js build failed without @types
   - Solution: Added @types/react and @types/node

4. **Git Tag Cleanup**
   - Issue: Old aspirational tags (v1.1.x, v1.2.0)
   - Solution: Deleted locally and remotely, kept only v1.0.0
